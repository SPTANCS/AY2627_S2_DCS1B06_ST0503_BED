The GET routes are already implemented. Your job is to complete the POST, DELETE, and PUT routes in index.js. Each question pair starts with an instructor-led walkthrough on /snacks, followed by a student DIY exercise on /electronics.

After all routes work, you'll wrap everything in try-catch for error handling.

Use API Client (e.g. Bruno, Postman) to test your routes.

Create — POST
Q1 POST /snacks Instructor Led

Add a new snack to the array. The request body will contain name, price, and quantity.

  1. 1 Extract name, price, quantity from req.body
  2. 2 Validate all three fields are present — if not, respond with an error JSON
  3. 3 Validate price is a positive number, quantity is a non-negative integer
  4. 4 Generate a new ID — copy the array, sort descending, take highest id + 1
  5. 5 Create a new object with { id, name, price, quantity }
  6. 6 Push to the snacks array and respond with the new object
  1. 7 Success response → res.status(201).json(...)
  2. 8 Validation errors → res.status(400).json(...)
Hints: typeof · Number.isInteger() · .slice() · .sort() · .push()
Q2 POST /electronics Student DIY

Follow the same pattern as Q1 to add a new electronic item. Same validation rules, same ID generation logic — just targeting the electronics array. Include proper status codes: 201 on success, 400 for validation errors.

Hints: req.body · typeof · Number.isInteger() · .slice().sort() · .push()
Delete — DELETE
Q3 DELETE /snacks/:id Instructor Led

Delete a snack by its ID. The ID comes from the URL parameter.

  1. 1 Get the id from req.params and convert to a number
  2. 2 Find the item in the snacks array
  3. 3 If not found, respond with an error JSON
  4. 4 Remove it from the array and reassign
  5. 5 Respond with the deleted item
  1. 6 Success response → res.status(200).json(...)
  2. 7 Not found → res.status(404).json(...)
Hints: Number() · .find() · .filter()
Q4 DELETE /electronics/:id Student DIY

Follow the same pattern as Q3 to delete an electronic item by ID. Include proper status codes: 200 on success, 404 if not found.

Hints: Number(req.params.id) · .find() · .filter()
Update — PUT
Q5 PUT /snacks/:id Instructor Led

Update a snack by its ID. Only update fields that are provided in the request body.

  1. 1 Get the id from req.params and convert to a number
  2. 2 Find the item in the snacks array
  3. 3 If not found, respond with an error JSON
  4. 4 Extract name, price, quantity from req.body
  5. 5 Only update fields that are provided — check !== undefined
  6. 6 Validate price and quantity before updating (same rules as POST)
  7. 7 Respond with the updated item
  1. 8 Success response → res.status(200).json(...)
  2. 9 Not found → res.status(404).json(...)
  3. 10 Validation errors → res.status(400).json(...)
Hints: .find() · !== undefined · typeof · Number.isInteger() · mutate the found object directly

Error Handling
Q7a POST Wrap POST /snacks handler in try-catch Instructor Led

Add a try-catch block inside the POST /snacks handler. If anything throws, catch it and return a 500 error.

  1. 1 Wrap the existing logic inside try { ... }
  2. 2 In the catch (err) block, return res.status(500).json({ error: err.message })
Hint: try { ... } catch (err) { res.status(500).json({ error: err.message }) }
