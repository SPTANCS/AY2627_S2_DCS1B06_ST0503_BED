201 Created New resource — POST
400 Bad Request Invalid / missing input
401 Unauthorized Not logged in / no token

500 Server Error Something broke server-side
JS Array Methods for CRUD
.find()
GET PUT

Returns the first element matching a condition. Ideal for fetching a single record by ID. Since it returns a reference, you can also use it to update fields directly.

// GET — look up by ID const user = users.find( u => u.id === req.params.id ) if (!user) return res.status(404).json({ error: 'Not found' }) // PUT — mutate the found object directly user.name = req.body.name
.filter()
GET DELETE

Returns a new array of all elements that pass a test. Used for listing with query params, or removing items.

// GET — filter by query param const active = users.filter(u => u.active === true) // DELETE — remove by ID users = users.filter(u => u.id !== req.params.id)
.push()
POST

Appends one or more elements to the end of an array, mutating it in place. The go-to for creating a new record.

const newUser = { id: Date.now(), ...req.body } users.push(newUser) res.status(201).json(newUser)
.sort()
GET

Sorts elements in place. Use a comparator for numbers/dates. Pair with req.query to let callers choose order.

// ascending by createdAt const sorted = [...items].sort( (a, b) => new Date(a.createdAt) - new Date(b.createdAt) )
.slice()
GET

Returns a shallow copy of a portion of an array. Essential for pagination with ?page= and ?limit= query params.

const page = Number(req.query.page) || 1 const limit = Number(req.query.limit) || 10 const start = (page - 1) * limit const paged = items.slice(start, start + limit)
Validation & Type Coercion
.some()
POST

Returns true if at least one element passes the test. Use it to check for duplicates before creating a new record.

const exists = users.some( u => u.email === req.body.email ) if (exists) return res.status(400).json({ error: 'Email taken' })
.includes()
POST PUT

Checks if a value exists in an array. Ideal for validating a field against a fixed list of allowed values before saving.

const ROLES = ['admin', 'editor', 'viewer'] if (!ROLES.includes(req.body.role)) { return res.status(400).json({ error: 'Invalid role' }) }
Array.isArray()
POST PUT

Guards against a body field that should be an array but isn't — e.g. a client sends a string instead of a list.

if (!Array.isArray(req.body.tags)) { return res.status(400).json({ error: 'tags must be an array' }) }
parseInt()  ·  Number()  ·  Number.isInteger()  ·  isNaN()
GET POST PUT DELETE

Everything from req.params and req.query arrives as a string. Coerce and validate before any logic, or comparisons silently break.

parseInt(req.params.id, 10) // "42" → 42 (always pass base 10) Number(req.query.page) || 1 // "3" → 3 (falls back to 1 if NaN) isNaN(id) // true if coercion failed — guard every parseInt Number.isInteger(Number(req.body.qty)) // rejects 3.5, "abc", undefined // typical guard pattern const id = parseInt(req.params.id, 10) if (isNaN(id)) return res.status(400).json({ error: 'ID must be a number' })
String Methods
.trim()
POST PUT

Removes leading and trailing whitespace. Always sanitize string fields from req.body before saving — users often paste values with accidental spaces.

const email = req.body.email.trim() // " hello@example.com " → "hello@example.com" const name = req.body.name?.trim() // ?. guards if field is undefined
.replace()  ·  .replaceAll()
POST PUT

Substitutes matched text with a replacement. Use a regex for pattern-based sanitization. .replaceAll() targets every occurrence; .replace() only the first unless given a /g flag.

// strip non-numeric chars from a phone field const phone = req.body.phone.replace(/\D/g, '') // "(65) 9123-4567" → "6591234567" // slugify a title for a URL const slug = req.body.title.trim().toLowerCase().replaceAll(' ', '-')
Async Iteration
for...of
POST PUT

The only safe way to use await inside a loop. Unlike .map(), it actually pauses execution at each iteration — runs sequentially, one item at a time.

// POST — insert a batch of items from req.body const created = [] for (const item of req.body.items) { const saved = await db.insert(item) // waits before next iteration created.push(saved) } res.status(201).json(created) // .map(async ...) does NOT await — returns [ Promise, Promise, ... ]
